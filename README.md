# clipsync

Share your clipboard across your Macs over [Tailscale](https://tailscale.com). Copy on one Mac, paste on another about a second later, with no distance limit (unlike Apple's Universal Clipboard, which needs the devices to be within Bluetooth range).

여러 대의 Mac 클립보드를 Tailscale로 자동 공유합니다. 한 Mac에서 복사하면 약 1초 뒤 다른 Mac에서 붙여넣을 수 있고, 애플 공용 클립보드와 달리 거리 제한이 없습니다.

## How it works

- One always-on Mac runs the **hub** (`hub.py`, Python standard library only). It keeps only the latest copied text, in memory.
- Every Mac (the hub included) runs the **client** (`clipsync`, a small Swift program started by launchd). It notices when you copy, sends the text to the hub, and long-polls the hub for text copied on your other Macs.
- Clients only make outbound connections to the hub, so a Mac behind a strict firewall (e.g. a managed work laptop) still works.

## Requirements

- macOS 14 or later, Apple Silicon
- Tailscale running on every Mac, all in the same tailnet
- On the hub Mac: Xcode Command Line Tools (`xcode-select --install`) for `swiftc` and `python3`

## Setup

On the hub Mac (pick one that stays on):

```bash
git clone https://github.com/sunjinpak/clipsync.git
cd clipsync
./setup-hub.sh
```

This builds the client, creates a random shared token in `~/.config/clipsync/token`, starts the hub at login, installs the client on this Mac, and prints a command like:

```bash
curl -fsS "http://100.x.y.z:8377/install?t=TOKEN" | bash
```

Run that command once in Terminal on each of your other Macs. That's it.

## Privacy and security

- Text is sent only over your tailnet (WireGuard-encrypted). The hub accepts requests only from Tailscale addresses (100.64.0.0/10) and localhost, and only with the shared token.
- The hub keeps just the most recent copy in memory. Nothing is written to disk or to logs.
- Copies that password managers mark as concealed or transient (`org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`, 1Password) are never sent.
- Treat the install command like a password: it contains the token. To rotate it, delete `~/.config/clipsync/token` on the hub, run `./setup-hub.sh` again, and rerun the new install command on each Mac.

## Limitations

- Plain text only (no images or files), up to 1 MB per copy.
- iPhone and iPad are not supported. Universal Clipboard still works for them when nearby.

## Troubleshooting

- Logs: `~/Library/Logs/clipsync.log` (client) and `~/Library/Logs/clipsync-hub.log` (hub).
- Restart the client: `launchctl kickstart -k gui/$(id -u)/local.clipsync`
- Add `CLIPSYNC_DEBUG=1` to the client's launchd environment to log each detected copy (type count and size only, never the content).

## Uninstall

On each Mac:

```bash
launchctl bootout gui/$(id -u)/local.clipsync
rm ~/Library/LaunchAgents/local.clipsync.plist ~/.local/bin/clipsync
rm -r ~/.config/clipsync
```

On the hub Mac, also:

```bash
launchctl bootout gui/$(id -u)/local.clipsync-hub
rm ~/Library/LaunchAgents/local.clipsync-hub.plist
```
